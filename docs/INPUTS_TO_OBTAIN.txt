# Inputs required to independently rerun the external MOPG-7 evaluation

The published source code uses:

1. Official **MOPG-7 Version 2** `annotations/instances_test.json` (210 images) — obtain from https://doi.org/10.17632/t66ytdrhf2.2.
2. Official `metadata/class_definitions.csv` from the **same version** of that dataset.
3. Archived model prediction JSONs (without image pixel data) named exactly:
   - `YOLOv8s_predictions.json`
   - `YOLO11s_predictions.json`
   - `RT_DETR_L_predictions.json`

The core public repository includes code and numerical reports, but **not** these three raw prediction JSONs pending the authors' release review. Use a private approved copy when replicating the analysis. The file SHA-256 hashes are documented in `results/external_reproduction_audit.json`.

With these files, run:

```bash
python code/reproduce_external_mopg7.py \
  --coco /path/to/annotations/instances_test.json \
  --class-definitions /path/to/metadata/class_definitions.csv \
  --predictions /path/to/prediction_jsons \
  --out external_reproduced_results
```

The script fails if the official reference counts or model thresholds do not match the fixed protocol; do **not** change the operating thresholds to force `PASS`.

The package does not recreate inference from weights or train the three models. Do not redistribute patient radiographs or private clinical identifiers.
